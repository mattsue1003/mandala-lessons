# 曼陀羅一圈一圈畫

24 個由簡到難的曼陀羅教案（★ 6–8 等份 3–4 圈、★★ 8–12 等份 5 圈、★★★ 12–16 等份 6–8 圈，各 8 課），跟著教學動畫一步一步完成：靜心呼吸 → 找中心畫大圓 → 同心圓 → 切等份 → 一圈一圈畫圖樣 → 擦鉛筆線 → 上色 → 簽名欣賞。

- 23 種圖樣，每一步附口語化畫法說明與帶領小提醒
- A4 學習單 PDF：畫線底稿、描線版、著色版（單課／全部 24 課含目錄）
- 自己設計：等份、配色、每一圈的圖樣與顏色，產生動畫與學習單
- 錄影（含字幕）、全螢幕投影、每一步唸出來、手機底部導覽
